# 电子显微学前沿课程网站 — 用户工作流文档

## 1. 用户角色

| 角色 | 权限 | 默认账号 |
|------|------|----------|
| **学生** | 注册/登录、使用所有 Agent 技能、打卡学习、管理文献收藏 | 自行注册 |
| **管理员** | 学生权限 + 管理知识库、视频、API Keys、评分模板、用户 | admin / admin123 |

## 4. 数据流

### 4.1 文献检索流

```
用户输入关键词/DOI
       │
       ▼
Agent 函数 (agent_skills.py)
       │
       ▼
OpenAlex 客户端 (openalex_client.py)
  ├─ search_works() → GET api.openalex.org/works?search=...
  ├─ get_work_by_doi() → GET api.openalex.org/works/doi:...
  └─ recent_works_by_topic() → 按日期筛选
       │
       ▼
返回结构化结果
  ├─ 标题 / DOI / 作者 / 期刊 / 日期
  ├─ 核心要点（关键词提取）
  ├─ 引用网络（节点 + 边）
  └─ 实验方法（概念提取）
       │
       ▼
用户可选择 → 收藏到文献收藏夹
               │
               ▼
          POST /api/literature/bookmark
          Body: {title, authors, journal, year, doi, source, category_id}
```

### 4.2 对话流

```
用户在聊天框输入问题
       │
       ▼
POST /api/agent-chat {question: "..."}
       │
       ▼
查找已配置的 API Key (ApiKey.is_active=True)
       │
       ▼
call_llm(api_key, provider, question)
  ├─ provider = "deepseek" → api.deepseek.com/v1/chat/completions
  └─ provider = "openai"   → api.openai.com/v1/chat/completions
       │
       ▼
返回 LLM 回答
       │
       ▼
保存到 ChatHistory (user + assistant)
       │
       ▼
显示在聊天框 + 下次刷新时加载历史
```

### 4.3 打卡流

```
用户设置学习计划
  ├─ 主题 / 每日数量 / 难度
  └─ POST /api/study/plan

每日进入 /study
  ├─ 加载今日知识点
  ├─ 加载对应测验题目
  └─ 用户作答

全部答对 → POST /study/checkin
  ├─ 创建 DailyCheckin 记录
  ├─ 增加分数 (beginner:10 / intermediate:20 / advanced:30)
  └─ 更新连续打卡天数

每周/月检测 → APScheduler 触发奖励
  ├─ 全勤（7天/月达标）
  └─ 创建 AttendanceReward → 种一棵树
```
